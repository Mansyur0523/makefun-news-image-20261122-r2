One newspaper front page summing up world news on **Sunday 22 November
2026** — 38 stories, 7 regions, drawn entirely in code with a hand-made
5×7 bitmap font. Round 2 revision: bigger type, shorter briefs, and a
thumbnail that still reads at 300px.

## The day in one line

COP31 collapsed in Antalya with no deal — the longest climate summit ever
and the first breakdown since Copenhagen 2009. Iran hit US-linked bases
in Bahrain on Saturday night. A Russian drone flattened a flat in Dymer,
near Kyiv. Verstappen won a 35-lead-change thriller in Las Vegas.
India declared 720/9 in Wellington. Anthropic sank 8.5% on Friday as
the AI selloff wiped out the Nasdaq's 2026 gains.
